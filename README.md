## About

I build full-stack products with a strong focus on real product behavior: authenticated flows, admin dashboards, API-backed screens, operational data, mobile/web parity and clean user experiences.

My work usually sits between product thinking and implementation. I care about how a system feels to use, but also about whether the data model, backend contracts and edge cases are solid enough for the product to grow.

## How I Like To Build

- Product screens should be backed by real APIs, not only visual mockups.
- Admin interfaces should be practical, editable and safe for repeated use.
- Frontend state should match backend truth instead of hiding integration gaps.
- Mobile and web experiences should share product rules when they represent the same workflow.
- Documentation should map the actual code paths, not just the ideal architecture.
